# WS Consortium — React TypeScript Homepage

Modern minimal white/blue themed homepage for WS Consortium Forum.

## 🚀 Setup Instructions

### Step 1 — Install dependencies
```bash
npm install
```

### Step 2 — Start development server
```bash
npm start
```
Opens at: http://localhost:3000

### Step 3 — Build for production
```bash
npm run build
```

## 🎨 Sections Included

1. **Navbar** — Fixed, transparent → white on scroll, with CTA
2. **Hero** — Headline, description, CTA buttons + Stats grid
3. **About** — Mission, approach, core values cards
4. **Expertise (Advisory)** — 6 expertise cards with hover effects
5. **Advisory Board** — 4 advisor profile cards
6. **Membership** — 3 pricing plans (Individual / SME / Corporate)
7. **Contact** — Contact info + membership application form
8. **Footer** — Links, info, copyright

---

## 🛠 Tech Stack

- React 18
- TypeScript
- CSS-in-JS (inline styles)
- No external UI libraries (pure React)
